# Discord Mod Bot

Полноценный Discord-бот для модерации сервера с системой ивентов, опросов,
заявок, тикетов, логов, веб-панелью и экономикой.

---

## Запуск на Pella

1. Зарегистрируйся на [pella.app](https://www.pella.app/signup).
2. Создай приложение **Discord Bot**.
3. Загрузи содержимое этой папки архивом или через GitHub.
4. Укажи команду запуска:

```bash
npm start
```

5. В разделе переменных окружения Pella добавь значения из списка ниже.
6. Нажми **Deploy/Start** и проверь логи приложения.

> В архиве нет токена. Никогда не добавляй токен в `config.js`, README или GitHub.
> Вводи его только в защищённое поле переменных окружения Pella.

### Обязательные переменные

| Переменная | Что указать |
|---|---|
| `TOKEN` | Токен бота из Discord Developer Portal → Bot → Reset Token/Copy |
| `PANEL_PASSWORD` | Новый пароль для веб-панели, не `admin123` |

### ID сервера и каналов

| Переменная | Назначение |
|---|---|
| `TARGET_ROLE_ID` | Ограничиваемая роль для целевых участников |
| `MOD_ROLE_ID` | Основная роль модератора |
| `MUTE_ROLE_ID` | Роль Muted |
| `MEMBER_ROLE_ID` | Роль, выдаваемая новым участникам |
| `LOG_CHANNEL_ID` | Канал логов |
| `WELCOME_CHANNEL_ID` | Канал приветствий |
| `APP_CHANNEL_ID` | Канал заявок |
| `TICKET_SUPPORT_ROLE_ID` | Роль поддержки тикетов |
| `ECONOMY_GUILD_ID` | ID сервера для экономики |

Чтобы копировать ID, включи в Discord: **Настройки → Расширенные → Режим разработчика**,
затем нажми правой кнопкой по серверу, роли или каналу → **Копировать ID**.

### Группы ролей

Каждая переменная ниже принимает один или несколько ID через запятую:

```text
DIRECTOR_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
DEPUTY_ROLE_IDS=ROLE_ID
MOD_PLUS_ROLE_IDS=ROLE_ID
MOD_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
APPS_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
REPRIMAND_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
REVIEW_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
TICKET_MOD_ROLE_IDS=ROLE_ID_1,ROLE_ID_2
ADMIN_ROLE_ID=ROLE_ID
```

Если группа не используется, оставь значение пустым. Администратор Discord
с разрешением Administrator всё равно сохраняет доступ к основным командам.

### Остальные переменные

```text
PREFIX=!
MOD_APP_ROLE_ID=
EVENT_APP_ROLE_ID=
HELPER_APP_ROLE_ID=
PANEL_PORT=3001
ECONOMY_STARTING_BALANCE=1000
ECONOMY_MAX_BET=1000000
ECONOMY_ADMIN_ROLE_ID=
```

`PORT` вручную добавлять не нужно: Pella назначает его сама. Бот использует
этот порт для веб-панели и не запускает второй сервер.

## Локальный запуск

```bash
cp .env.example .env
# заполни .env
npm install
npm start
```

Проверка настроек без подключения к Discord:

```bash
npm run check-config
```

Для быстрой проверки ответа бота в Discord используй:

```text
!пинг
```

Ожидаемый ответ: `Понг! Бот получает сообщения.`

Если бот отображается онлайн, но `!пинг` не отвечает:

1. Открой Discord Developer Portal → приложение бота → **Bot**.
2. Включи **Message Content Intent**.
3. Нажми **Save Changes**.
4. Перезапусти приложение на Pella.
5. Убедись, что команда начинается с `!`, если переменная `PREFIX` не изменена.

Если в логах Pella есть `An invalid token was provided`, создай новый токен
через **Reset Token** и замени значение `TOKEN` в Pella. Никому не отправляй
токен в чат.

## Разрешения Discord

Выдай боту роль с правами:

- Manage Roles
- Kick Members
- Ban Members
- Manage Messages
- View Channels
- Send Messages
- Read Message History

Для работы с сообщениями также включи в Discord Developer Portal → Bot:

- **Message Content Intent**
- **Server Members Intent**
- **Presence Intent** — не обязателен, но рекомендуется для расширения функциональности

Создай роль `Muted` и запрети ей отправку сообщений в нужных каналах.

## 🔒 Система ролей
- **MOD_ROLE_ID** — только эта роль может использовать команды модерации
- **TARGET_ROLE_ID** — !кик и !бан работают только на участников с этой ролью
- Администраторы сервера могут использовать все команды

## Продажа ролей за валюту бота

| Команда | Кто может | Что делает |
|---|---|---|
| `/role-sell role price [description]` | только разработчики (`DEVELOPER_USER_IDS` / `DEVELOPER_ROLE_IDS` / Administrator) | выставляет роль в магазин; повторный вызов обновляет цену |
| `/role-unsell role` | только разработчики | снимает роль с продажи |
| `/role-listings` | все | показывает роли в продаже и статус выдачи |

Перед выставлением и перед каждой покупкой бот проверяет, что роль реально можно выдать:
роль существует, это не `@everyone`, она не управляется интеграцией, у бота есть право
**Управление ролями**, и его высшая роль стоит выше продаваемой.

Покупка идёт в `/shop` кнопкой «Купить #ID». Деньги списываются только после успешных
проверок, а если Discord всё же откажет в выдаче роли — сумма возвращается автоматически.

## 🤖 ИИ-ассистент (Groq) — v1.3

Бот отвечает как ИИ на сообщения в указанных каналах: помнит контекст диалога,
знает все команды бота и умеет назвать состав штатных ролей сервера.

1. Получи бесплатный ключ на https://console.groq.com/keys (вид `gsk_...`).
2. Впиши значения в `.env` (или в переменные окружения хостинга):
   ```env
   GROQ_API_KEY=gsk_твой_ключ
   AI_CHANNEL_IDS=1537056437115560036
   AI_ROLE_MODERATOR_ID=ID_РОЛИ
   AI_ROLE_LEGENDARY_ID=ID_РОЛИ
   AI_ROLE_DEPUTY_ID=ID_РОЛИ
   AI_ROLE_DIRECTOR_ID=ID_РОЛИ
   ```
3. `npm install` → `npm start`.

- По умолчанию отвечает в канале `1537056437115560036`; список можно изменить через `AI_CHANNEL_IDS`.
- Помнит последние `AI_HISTORY_LIMIT` пар сообщений в канале.
- `!ai-reset` — очистить историю диалога в канале.
- `AI_ENABLED: false` — выключить ИИ.
- Нужны интенты **MESSAGE CONTENT** и **SERVER MEMBERS** в Discord Developer Portal.
- Роли без указанного ID просто не используются ИИ — ошибок не будет.

## ⚙️ Где менять ключ и ID — `.env`

Все токены, ключи и ID задаются переменными окружения: файл `.env` рядом с `index.js`
локально, либо раздел Environment Variables в панели хостинга (Pella и т.п.).
Шаблон со всеми переменными — в `.env.example`. Файл `config.js` править не нужно.

> `.env` не выкладывай в публичный GitHub — он в `.gitignore`.
